## 核心龙头（Core Leader）子模式

### CL-001: 主线趋势龙头

**描述**：产业逻辑发生重大变化后，最先被机构资金推动、沿均线上行的趋势核心。不靠连板，靠持续性强。

**识别条件**：
1. 所属板块有硬产业催化（涨价/产能紧缺/政策驱动/业绩爆发）
2. RS_20 > 0.5（相对强度显著高于市场）
3. 站上MA5和MA20，回踩不破MA10
4. 成交额持续在板块内排名前列（机构行为特征）
5. 板块内形成"龙头+中军+跟风"梯队结构

**入场信号**：
- 板块第一次放量强化时右侧跟随
- 沿MA5/MA10回踩缩量时低吸
- 指数下杀但该股不破位时加仓

**退出标准**：
- 放量滞涨（成交额放大但股价不涨）
- 跌破MA5且次日不能收回
- 板块逻辑证伪（产业催化消退）

- 趋势龙头的关键是"持续"而非"爆发"，不要期待涨停

### CL-002: 连板题材龙头

**描述**：与当日最强板块对齐的连板高度标，是板块情绪的集中体现。板块强则龙头强，龙头断则板块退。

**识别条件**：
1. 连板高度 >= 3板（说明不是偶然首板）
2. 所属板块为当日涨停数最多或资金量最大的方向
3. 板块内有完整的连板梯队（2板+3板助攻）
4. 有明确的产业催化或事件驱动
5. 非一字板（有换手机会可以参与）

**入场信号**：
- 换手板：封板前低吸或封板瞬间跟随
- 打开回封：最后一次回封时介入（确认分歧转一致）
- 次日竞价：超预期高开后快速拉升（确认市场认可）

**退出标准**：
- 断板且板块内无新的连板股接力
- 板块涨停数骤降（从前日的10+降到3以下）
- 市场高度被压缩（从5板降到3板以下）

**历史案例**：
- 2026-04-13 圣阳股份(002580)：3板连板龙，液冷服务器方向，板块涨停2只+金额61亿，次日4/16液冷大会催化。打开回封类型，窗口约5分钟，difficulty=easy。

**备注**：
- 连板龙最怕"孤军深入"——高度很高但板块没有梯队支撑
- 区分"情绪龙"（纯博弈高度）和"题材龙"（有产业逻辑）：只做题材龙
- 一字板类型的连板龙虽然强但无法参与，只作为情绪风向标

### CL-003: 板块中军放量突破

**描述**：板块中的容量核心股（流通市值偏大、成交额排名前列），放量突破长期震荡区间。机构资金入场信号。

**识别条件**：
1. 流通市值 > 200亿（中大盘股，机构可配）
2. 当日成交额较前5日均值放大 >= 50%
3. 突破近20日震荡区间上沿
4. 所属板块为当日热点方向
5. 近5日无涨停（不是情绪票，是趋势票）

**入场信号**：
- 突破当日收盘前买入（确认突破有效）
- 次日回踩突破位不破时低吸
- 板块首次强化时跟随

**退出标准**：
- 跌破突破位（假突破）
- 放量冲高后缩量回落（资金出逃）
- 板块逻辑弱化

**历史案例**：
- 2026-04-13 中国巨石(600176)：电子布龙头，37.69亿成交额首板涨停，玻纤涨价+Low-DK电子布供不应求逻辑，放量突破前期平台。但首板非中军典型（涨停偏情绪），需观察次日是否转为趋势。

**备注**：
- 中军的核心特征是"容量"和"持续性"，涨停反而不一定是好事（容易透支）
- 放量突破后最怕次日缩量——说明资金只是一次性冲进来
- 优先选"突破+有板块效应"的，不要选"突破但板块不跟"的

## 结构性机会（Structural Edge）子模式

### SE-001: 错杀修复（竞价预期差）

**描述**：前一日因情绪退潮或板块拖累被"错杀"（跌停/大跌），但个股自身有其他热点属性锚定。次日竞价/开盘表现远超"理所当然"的悲观预期，说明市场正在重新定价。

**识别条件**：
1. 前一日跌停或大跌 > 7%（被错杀）
2. 个股自身至少有一个匹配当日热门板块的属性（不是纯垃圾股）
3. 次日竞价结果远超预期：
   - 前日跌停 → 次日竞价跌幅 < 3%（预期差极大）
   - 前日大跌 → 次日竞价翻红（预期差极大）
4. 盘中 tick 数据显示前日有做多动作（撬板/反弹/放量）
5. 是首次大跌，不是连续杀跌（连跌 = 真杀，不是错杀）

**入场信号**：
- **竞价确认**：9:25 集合竞价结果出来后，若符合条件3，直接竞价买入
- **开盘确认**：若竞价未达标但开盘后5分钟内快速翻红，半路跟进
- **量价确认**：在关键价位（如昨日跌停价）出现明显放量承接

**退出标准**：
- 开盘30分钟内未能站上均价线 → 减仓
- 匹配的热门板块当日走弱 → 止损（逻辑崩塌）
- 同板块无联动，孤军奋战 → 谨慎，不追加

**历史案例**：
- 2026-04-14 中嘉博创(000889)：前日(4/13)跌停-9.89%（3板断板），但次日(4/14)竞价仅-0.77%，开盘后快速拉升。预期差显著：3连板断板按理应继续大跌甚至核按钮，但竞价仅微跌说明有资金在低位承接。这是一个典型的"定价修正"机会。

**备注**：
- 错杀修复的关键判断是"预期差大小"——前日越恐慌（跌停），次日越温和（微跌/高开），预期差越大
- 必须有"确认信号"，不能在竞价前就盲目挂单——竞价结果是确认信号
- 止损要果断：如果开盘后反而继续杀跌，说明不是错杀而是真杀

### SE-002: 连板卡位（高度接力）

**描述**：当前市场最高板（高度标）出现走弱迹象，而潜在的继任者（次高板或新晋连板股）展现出接力的意图和能力。此时介入继任者，博弈其成为新的市场高度标。

**识别条件**：
1. 当前最高板出现走弱信号：
   - 水下开盘（低开 > 2%）
   - 开盘后快速下跌（5分钟内跌幅扩大）
   - 竞价阶段放量但价格走低
2. 存在明确的潜在继任者：
   - 次高板（当前最高板-1板）高开或竞价走强
   - 与热门板块对齐，有板块效应支撑
3. 继任者开盘即封板或快速拉升（确认接力意图）
4. 市场情绪整体不算太差（涨停数 > 30，封板率 > 60%）

**入场信号**：
- **确认信号**：原最高板开盘走弱 + 继任者高开/秒板 → 继任者封板瞬间或封板前介入
- **时间窗口**：通常在开盘5-15分钟内完成确认
- **替代方案**：若继任者一字板无法买入，考虑次高板中的换手板

**退出标准**：
- 继任者封板后又打开且无法回封 → 止损（接力失败）
- 原最高板反而回封（假弱真强）→ 减仓（竞争格局不明朗）
- 次日竞价低开（市场不认可新高度标）→ 止损

**历史案例**：
- 2026-04-10 华远控股(600743)：当日原最高板5板的汇源通信水下开盘后快速下跌，华远控股作为4板次高标高开秒板，接替成为市场最高标（4板→后续走到5板）。这是一个经典的"高位接力"机会，窗口在开盘前5分钟。

**备注**：
- 卡位成功的关键是"继任者有辨识度"——市场所有短线资金都在看谁能接棒
- 最怕的是"高位双杀"——原高度标和继任者都走弱，说明市场整体退潮
- 需要结合封板率判断市场环境：封板率低(<60%)时不宜接力

### SE-003: 板块弱转强

**描述**：一个板块前一日处于分歧状态（涨停打开、冲高回落、板块内个股分化），但今日竞价/开盘后核心票率先封板，带动板块从分歧转为一致。

**识别条件**：
1. 前一日板块处于分歧：
   - 板块内涨停股少于3只，或涨停被打开
   - 板块核心票冲高回落
2. 今日竞价/开盘表现超预期：
   - 板块核心票竞价高开 > 3%
   - 开盘5分钟内快速封板
3. 板块内出现跟风效应：
   - 板块内至少2只其他票同步拉升
   - 板块整体涨幅排名快速上升
4. 有催化事件或逻辑支撑（不是纯情绪反转）

**入场信号**：
- 核心票封板瞬间跟随（打板）
- 封板后的首次回封（分歧转一致的二次确认）
- 板块内最先跟风的二线票（助攻机会）

**退出标准**：
- 核心票封板后又打开，板块无后续 → 止损
- 次日板块未能继续走强 → 获利了结
- 发现更强的板块抢走资金 → 切换
